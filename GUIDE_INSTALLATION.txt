AFTER DARK — PACK CORRIGÉ

CONTENU
- index.html : application locale corrigée, avec 600 cartes classiques, 25 Mythiques, parcours conditionnel et sauvegarde locale.
- catalogue_600.json : catalogue indépendant de 600 cartes.
- cartes_mythiques.json : 25 cartes Mythiques séparées, liées aux succès.
- supabase.sql : schéma antérieur + import idempotent du catalogue classique et Mythique.
- LISEZ_MOI.txt : état et limites.

INSTALLATION GITHUB PAGES
1. Ouvre le dépôt https://github.com/yoangonzales51-hub/After-dark
2. Remplace index.html par celui de ce pack et publie le commit sur la branche GitHub Pages.
3. Conserve manifest.webmanifest, sw.js et le dossier icons déjà présents dans le dépôt.
4. Recharge le site ; si la PWA garde l'ancienne version, ferme-la complètement puis rouvre-la.

SUPABASE
Le SQL contient les tables et les données de catalogue, mais le mode deux téléphones n'est pas encore raccordé dans l'interface. Ne lance pas de partie à distance et n'utilise jamais une clé service_role dans le navigateur.

SAUVEGARDE
La progression locale est enregistrée dans le navigateur. Les anciennes données AFTER DARK v3/v4 sont reprises pour les noms, cartes personnelles, historique et listes ; une ancienne partie inachevée peut devoir être recommencée pour appliquer le nouveau moteur. Exporte régulièrement une sauvegarde depuis Réglages.
