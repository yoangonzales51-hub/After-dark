AFTER DARK — ÉTAPE 3 : CONNEXION ET ASSOCIATION DES COMPTES

CONTENU
- index.html : interface d'origine conservée (mode local, catalogue, cartes perso, stats, export/import) avec ajout de la connexion Supabase par e-mail et de la création/rejointure d'un couple par code.
- manifest.webmanifest, sw.js et icônes : préparation PWA.

CE QUI EST IMPLÉMENTÉ DANS CETTE ÉTAPE
- Création de compte e-mail/mot de passe et connexion Supabase Auth.
- Session persistante gérée par le SDK Supabase.
- Création d'un couple via create_couple, génération d'un code privé.
- Rejointure via join_couple.
- Vérification de l'association du compte.
- Le mode local existant est conservé.

CE QUI N'EST PAS ENCORE IMPLÉMENTÉ
- Les parties et réponses ne sont pas encore synchronisées entre téléphones.
- Le parcours de jeu à distance doit encore être raccordé aux tables game_sessions/session_answers et testé avec deux comptes réels.
- Le déploiement HTTPS et l'installation sur Android ne sont pas effectués par cette archive.

INSTALLATION / TEST
1. Décompresser l'archive.
2. Héberger gratuitement le contenu du dossier sur un hébergement statique HTTPS (sans acheter de domaine; vérifier les limites de l'offre gratuite).
3. Ouvrir l'URL HTTPS dans Chrome Android.
4. Tester d'abord la création de compte puis la connexion sur chaque téléphone.
5. Premier téléphone : saisir un pseudonyme et choisir « Créer un couple ». Transmettre le code affiché en privé.
6. Deuxième téléphone : créer son propre compte, saisir son pseudonyme et le code, puis choisir « Rejoindre le couple ».

AUTHENTIFICATION
- Supabase Auth Email doit rester activé.
- Si la confirmation d'e-mail est activée, chaque personne doit confirmer son adresse avant de se connecter.
- Dans Supabase Authentication > URL Configuration, renseigner le Site URL et les Redirect URLs avec l'adresse HTTPS réelle du site après hébergement. Ne pas utiliser localhost pour le site public.

SÉCURITÉ
- La clé publishable est destinée au navigateur; aucune clé service_role ne doit être ajoutée au frontend.
- Ne partagez jamais le code d'invitation publiquement. Il expire après 24 h et est à usage unique selon la fonction SQL installée.
- Cette étape n'est pas une certification de sécurité. Les tests d'accès et de synchronisation restent à faire.
- Ne pas activer de plan payant ni de dépassement automatique. Rester sur Supabase Free et hébergement gratuit.
